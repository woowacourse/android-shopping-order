# android-shopping-cart


### 3단계 테스트

- [x] 상품 목록에서 `+` 버튼 클릭 시 장바구니 수량이 1 증가한다.
- [x] 같은 상품을 상품 목록/상품 상세/장바구니 어디서 변경해도 수량이 동기화된다.
- [x] 수량이 0이 되면 장바구니에서 해당 상품이 제거된다.
- [x] 수량은 음수가 될 수 없다.
- [x] 프로세스 재생성(상태 복원) 이후에도 수량이 유지된다.
- [x] 수량 선택 공통 컴포넌트가 최소/증가/감소 동작을 정상 처리한다.
- [x] 장바구니에서 x를 누르면 수량이 몇게가 있던 삭제된다.

### 4단계 테스트

- [x] 최근 본 상품이 최신 순으로 정렬되고 최대 10개까지만 유지된다.
- [x] 마지막으로 본 상품 1개가 상세 화면에 노출된다.
- [x] 마지막으로 본 상품을 클릭하면 최근 본 상품 영역에서 해당 상품이 제외된다.
- [x] 마지막으로 본 상품 화면에서 뒤로 가기 시 상품 목록으로 이동한다.
- [x] 앱 재시작 후 최근 본 상품 목록과 장바구니 데이터가 유지된다.
