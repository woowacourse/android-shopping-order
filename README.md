## 🚀 2단계 - 상품 추천

## 🎯 기능 목록

### 장바구니 선택 주문
- [ ] 장바구니 화면에서 상품을 선택할 수 있다.
- [ ] 선택된 상품만 주문 대상에 포함한다.
- [ ] 선택한 상품이 없을 경우 주문 버튼을 비활성화한다.
- [ ] 선택 상태에 따라 주문 버튼 상태를 갱신한다.

### 상품 추천
- [ ] 별도의 상품 추천 화면을 구현한다.
- [ ] 최근 본 상품의 카테고리를 기준으로 추천 상품을 조회한다.
- [ ] 가장 최근에 본 상품의 카테고리 상품을 최대 10개까지 노출한다.
- [ ] 해당 카테고리 상품이 10개 미만이면 가능한 개수만 노출한다.
- [ ] 장바구니에 이미 추가된 상품은 추천 목록에서 제외한다.
- [ ] 추천 가능한 상품이 없는 경우 빈 상태 UI를 노출한다.

### 추천 상품 장바구니 추가
- [ ] 추천 상품 화면에서 상품을 바로 장바구니에 추가할 수 있다.
- [ ] 추천 상품을 장바구니에 추가하면 함께 주문할 수 있다.
- [ ] 추천 상품 추가 후 장바구니 상태를 갱신한다.

## 🧪 테스트 명세

### 장바구니 선택 주문 테스트
- [ ] 장바구니에서 특정 상품만 선택할 수 있다.
- [ ] 선택된 상품만 주문 대상에 포함된다.
- [ ] 선택한 상품이 없으면 주문 버튼이 비활성화된다.

### 상품 추천 테스트

- [ ] 추천 상품은 최대 10개까지만 반환된다.
- [ ] 해당 카테고리 상품이 10개 미만이면 가능한 개수만 반환된다.
- [ ] 장바구니에 이미 담긴 상품은 추천 목록에서 제외된다.

### 추천 상품 장바구니 추가 테스트
- [ ] 추천 상품을 장바구니에 추가할 수 있다.
- [ ] 추천 상품 추가 후 장바구니 상태가 갱신된다.
