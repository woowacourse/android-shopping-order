# android-shopping-order

# 🚀 1단계 - 서버 연동 & 2단계 - 상품 추천

## 1단계 구현 기능 목록

### 인증 처리

- [x] 앱 실행 시 제공된 인증 정보를 로컬에 저장한다.
- [x] 사용자 인증 정보를 API 요청 헤더에 포함한다.
- [x] 네트워크 예외 상황을 처리한다.

### 상품 API 연동

- [x] `page`, `size`기반으로 상품 목록을 조회 API을 연동한다.
- [x] `id`를 통해 상품 상세 내용을 조회 API을 연동한다.

### 장바구니 API 연동

- [x] 장바구니 조회 API을 연동한다.
- [x] 장바구니 추가 API을 연동한다.
- [x] 장바구니 수정 API을 연동한다.
- [x] 장바구니 삭제 API을 연동한다.

### 서버 연동

- [x] Retrofit 기반으로 서버와 연동한다.
- [x] Kotlinx Serialization 기반 JSON 직렬화를 적용한다.
- [x] Interceptor를 정의하여 사용자 인증정보를 헤더에 포함한다.

### 로딩 UI 개선

- [x] 상품 목록 로딩 시 스켈레톤 UI를 표시한다.
- [x] 장바구니 로딩 시 스켈레톤 UI를 표시한다.

## 2단계 구현 기능 목록

### 장바구니 화면

- [x] 장바구니 상품 선택 기능
    - [x] 상품 별로 선택할 수 있다.
    - [x] 전체 상품을 선택할 수 있다.
    - [x] 선택된 상품의 금액과 개수를 표시한다.
- [ ] 주문하기
    - [ ] 주문하기 버튼 클릭 시 상품 추천 화면을 표시한다.

### 장바구니 - 추가 상품 추천 화면

- [ ] 가장 최근 상품의 카테고리와 동일한 상품 최대 10개를 노출한다.
    - [ ] 장바구니에 존재하는 상품이라면 노출하지 않는다.
- [ ] 상품을 추가/수정/삭제할 수 있다.
- [ ] 총 상품의 금액과 개수를 표시한다.
- [ ] 주문하기 버튼을 통해 주문한다.
