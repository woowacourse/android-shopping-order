## 🚀 3단계 - Navigation

## 🎯 기능 목록

### Navigation
- [x] Compose Navigation으로 화면 전환을 구현한다.
- [x] 상품 목록 화면을 Navigation destination으로 구성한다.
- [x] 상품 상세 화면을 Navigation destination으로 구성한다.
- [x] 장바구니 화면을 Navigation destination으로 구성한다.
- [x] 상품 추천 화면을 Navigation destination으로 구성한다.
- [x] 기존 Activity 전환 방식을 제거하고 `navigation-compose` 기반으로 교체한다.
- [x] 모든 Route는 `@Serializable` 타입으로 선언한다.
- [x] 화면 이동은 `NavController`를 통해 처리한다.
- [x] 화면 Composable에 `NavController`를 직접 전달하지 않고 이동 로직을 콜백 람다로 분리한다.
- [x] 주문 완료 후 상품 목록으로 이동할 때 주문 흐름이 Back Stack에 남지 않도록 처리한다.

### Flow
- [x] 기존 `remember`, `mutableStateOf` 기반 상태를 `StateFlow`, `SharedFlow`로 교체한다.
- [x] ViewModel의 UI 상태는 `MutableStateFlow`로 관리한다.
- [x] 외부에는 `StateFlow`로 노출한다.
- [x] 스낵바, 화면 이동 같은 일회성 이벤트는 `MutableSharedFlow`를 사용한다.
- [x] Composable에서는 `collectAsState()` 대신 `collectAsStateWithLifecycle()`를 사용한다.

## 🚀 4단계 - 주문 & 알림

## 🎯 기능 목록

### 최종 주문
- [x] 장바구니에 담긴 상품을 최종 주문할 수 있다.
- [x] 결제 수단 선택 없이 결제하기 버튼을 누르면 바로 주문을 완료한다.
- [x] 최종 주문이 완료되면 상품 목록 화면으로 이동한다.
- [x] 최종 주문이 완료되면 장바구니에서 주문된 상품이 초기화된다.
- [ ] 쿠폰을 사용해도 쿠폰 데이터는 사라지지 않도록 유지한다.

### 배송비
- [x] 기본 배송비를 `3,000원`으로 적용한다.
- [ ] 무료 배송 쿠폰이 적용되면 배송비를 `0원`으로 계산한다.
- [ ] 무료 배송 쿠폰은 도서 및 산간 지역에도 동일하게 적용한다.

### 쿠폰 조회 및 적용
- [x] 결제 화면에서 적용 가능한 쿠폰 목록을 조회할 수 있다.
- [ ] 쿠폰은 한 번에 1개만 적용할 수 있다.
- [ ] 쿠폰 적용 시 주문 금액과 할인 금액을 올바르게 반영한다.
- [ ] 쿠폰 조건을 만족하지 않으면 적용할 수 없다.

### 쿠폰 정책
- [ ] `FIXED5000` 쿠폰은 `100,000원` 이상 주문 시 `5,000원`을 할인한다.
- [ ] `BOGO` 쿠폰은 동일한 상품을 `3개` 담은 경우 `1개` 가격만큼 할인한다.
- [ ] `BOGO` 쿠폰은 `3개`씩 담긴 상품이 여러 개면 가장 비싼 상품 1개에 적용한다.
- [ ] `FREESHIPPING` 쿠폰은 `50,000원` 이상 주문 시 배송비를 무료로 처리한다.
- [ ] `MIRACLESALE` 쿠폰은 오전 `4시`부터 `7시` 사이에만 `30%` 할인을 적용한다.
- [ ] 각 쿠폰의 만료일을 고려해 사용 가능 여부를 판단한다.

### 미결제 알림 설정
- [ ] 설정 화면에서 미결제 알림 기능을 On/Off 할 수 있다.
- [ ] 미결제 알림 설정 상태를 `SharedPreferences`에 저장한다.
- [ ] 앱을 재실행해도 저장된 설정을 유지한다.

### 알림 예약 및 취소
- [ ] 결제 화면에 진입하면 `AlarmManager`로 `5분` 뒤 알림을 예약한다.
- [ ] 결제를 완료하면 예약된 알림을 취소한다.
- [ ] 결제 화면으로 돌아오면 예약된 알림을 취소한다.
- [ ] 결제 화면에 재진입할 때 기존 예약이 있으면 정리한 뒤 다시 예약한다.

### 알림 노출 및 이동
- [ ] `BroadcastReceiver`로 예약된 알람을 수신한다.
- [ ] `NotificationManager`로 "아직 결제가 완료되지 않았어요" 알림을 노출한다.
- [ ] 알림 클릭 시 결제 화면으로 이동한다.
- [ ] `POST_NOTIFICATIONS` 권한을 요청한다.
- [ ] 알림 권한 Dialog와 Notification UI는 시스템 기본 UI를 사용한다.
- [ ] Notification 아이콘은 커스텀 리소스를 사용한다.
