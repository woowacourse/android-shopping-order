# 🚀 4단계 - 주문 & 알림

## 🎯 기능 목록

### 주문 및 결제 (Payment)
- [x] 장바구니에 담긴 상품을 최종 주문할 수 있다.
- [x] 결제 화면에서 적용 가능한 쿠폰을 조회하고 1개만 선택하여 적용할 수 있다.
- [x] 결제하기 버튼 클릭 시 결제 수단 입력 없이 즉시 최종 주문이 완료된다.
- [x] 최종 주문이 완료되면 성공적으로 상품 목록 화면으로 이동한다.
- [x] **[API 연동]** 최종 주문이 완료되면 장바구니에서 주문된 상품이 정상적으로 초기화(삭제)된다.
- [x] **[API 연동]** 쿠폰을 사용해도 쿠폰 목록에서 사라지지 않고 유지된다.

### 쿠폰 도메인 로직 (Domain)
- [x] **5,000원 할인 쿠폰 (FIXED5000)**: 최소 주문 금액 100,000원 이상 시 5,000원 할인 적용 (만료일: 2024-11-30).
- [x] **2개 구매 시 1개 무료 쿠폰 (BOGO)**: 장바구니에 동일 제품 3개 이상 담은 경우 1개 가격 할인, 여러 개일 경우 가장 비싼 제품에 적용 (만료일: 2024-05-30).
- [x] **무료 배송 쿠폰 (FREESHIPPING)**: 최소 주문 금액 50,000원 이상 시 배송비(3,000원) 무료 처리 (만료일: 2024-08-31).
- [x] **미라클모닝 30% 할인 쿠폰 (MIRACLESALE)**: 오전 4시~7시 사용 시 30% 할인 적용 (만료일: 2024-07-31).

### 미결제 알림 기능 (Notification)
- [x] 앱 설정에서 미결제 알림 기능 On/Off가 가능하며, 재실행 시에도 상태가 유지된다 (`SharedPreferences` 사용).
- [x] 안드로이드 13(Tiramisu) 이상 기기에서 알림 권한(`POST_NOTIFICATIONS`)을 요청한다.
- [x] 결제 화면 진입 시 `AlarmManager`를 활용하여 5분 후 알림을 예약한다.
- [x] 결제가 완료되거나 결제 화면에 재진입하면 기존 예약된 알람을 취소한다.
- [x] 5분 초과 시 `BroadcastReceiver`를 통해 "아직 결제가 완료되지 않았어요"라는 알림을 시스템에 노출한다.
- [x] Notification 아이콘을 커스텀 아이콘으로 지정한다.
- [x] 사용자가 알림을 클릭하면 결제 화면으로 바로 이동한다.


# 🚀 3단계 - Navigation & Flow

## 🎯 기능 목록

### 화면 전환 (Navigation)
- [x] 기존 Activity 간 전환 방식을 모두 제거하고 Compose Navigation(`navigation-compose`) 기반으로 마이그레이션한다.
- [x] 모든 화면 이동은 `NavController`를 통해 중앙 집중식으로 제어한다.
- [x] 화면 이동 로직을 Composable에서 분리하고 콜백(Callback) 람다로 전달한다.
- [x] 화면 전환 시 전달하는 데이터를 타입 안전(Type-Safe)하게 보장하기 위해 `@Serializable` 데이터 클래스 기반의 `Route`를 정의한다.
- [x] 주문 완료 후 상품 목록으로 돌아갈 때, Back Stack에 이전 주문 과정이 남지 않도록 백스택을 정리(`popUpTo`)한다.

### 상태 관리 고도화 (Flow)
- [x] ViewModel의 기존 상태 관리 방식을 `MutableStateFlow` 및 `StateFlow`로 완전히 전환한다.
- [x] 장바구니 담기 성공, 결제 완료, 스낵바 표시 등 한 번만 발생해야 하는 단발성 이벤트(One-shot Event)는 `SharedFlow`(`MutableSharedFlow`)를 사용하여 처리한다.
- [x] 화면(UI)에서 ViewModel의 상태를 구독할 때 생명주기를 인지하여 리소스를 절약하는 `collectAsStateWithLifecycle()`을 일괄 적용한다.


# 🚀 2단계 - 상품 추천

## 🎯 기능 목록

### 장바구니 화면 (UI)

- [x] 각 상품별로 선택/해제할 수 있는 기능(체크박스 등)을 구현한다.
- [x] 사용자가 선택한 특정 상품들만 포함해 '주문하기' 버튼을 눌러 주문을 완료한다
- [x] 전체 상품을 선택할 수 있다.
- [x] 주문하기 옆에 상품 종류 개수와 전체 계산된 가격을 보여준다.

### 상품 추천 화면 (UI)

- [x] 장바구니에서 주문하기 버튼을 누르면 화면에 추천 상품 목록을 노출한다.
- [x] 추천된 상품 아이템마다 '장바구니 추가' 버튼을 구현하여 즉시 함께 주문할 수 있도록한다.

### 상품 추천 알고리즘 (Domain)

- [x] 사용자가 가장 최근에 본 상품의 카테고리를 식별한다.
- [x] 해당 카테고리와 일치하는 상품을 목록에서 필터링한다.
- [x] 이미 장바구니에 추가된 상품은 추천 목록에서 완전히 제외한다.
- [x] 필터링된 추천 상품이 10개 이상일 경우 최대 10개만 반환한다.
  - [x] 10개 미만일 경우 존재하는 개수만큼만 반환한다.
- [x] 추천 화면에서 상품을 추가하면 장바구니가 업데이트 된다.

### 주문 데이터 (Domain)
- [x] 주문 API 연동
  - [x] 주문 생성 요청 모델 정의
  - [x] 주문 결과 응답 처리

### 테스트 요구 사항 (Test)

#### 상품 추천 알고리즘 테스트
- [x] 가장 최근에 본 상품의 카테고리를 기준으로 추천 목록이 생성되는지 검증한다.
- [x] 추천 목록이 최대 10개까지만 노출되는지 검증한다.
- [x] 추천 대상 상품이 10개 미만일 때, 해당 개수만큼만 정확히 노출되는지 검증한다.
- [x] 장바구니에 이미 담겨있는 상품은 추천 목록에서 제외되는지 검증한다.
