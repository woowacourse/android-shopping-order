# 기능 구현 사항

## 1단계 구현 기능 사항

## UI
- [x] 상품 카드 스켈레톤 UI 컴포넌트 구현
- [x] 카트 카드 스켈레톤 UI 컴포넌트 구현

## 데이터(서버)
- [x] 서버와 연동한다.
  - [x] 상품 목록을 조회할 수 있다.
  - [x] 상품 상세를 조회할 수 있다.
  - [x] 카트 정보를 조회할 수 있다.
  - [x] 카트 아이템을 추가, 삭제, 변경 할 수 있다.
- [x] 사용자 인증 정보를 저장한다.

## 2단계 구현 기능 사항

## UI
- [x] 카트 아이템에 체크 박스 추가
- [x] 카트 하단 바 구현
  - [x] 전체 선택 체크 박스가 있다.
  - [x] 선택한 카트의 가격을 표시한다.
  - [x] 주문하기 버튼이 있다.
- [x] 상품 추천 화면을 구현한다.
  - [x] 최근 본 상품을 기반으로 api를 요청하고, 최대 10개 추천 상품을 띄운다.
- [x] 주문하기 버튼을 눌렀을 때 최근 본 상품이 있다면, 추천 화면으로 이동한다.
  - [x] 최근 본 상품이 없다면, 다음 화면으로 이동한다. (지금은 없으므로, 기존 화면이 유지된다.)

## 도메인
- [x] 선택된 카트 아이템들의 총 가격을 계산할 수 있다.

## 3단계 구현 기능 사항
- [x] 기존 화면들을  Navigation Component로 구성
  - [x] 화면 이동 시 전달하는 데이터는 타입 안전한 Route를 사용한다.
  - [x] 앱 시작 시 Shopping 화면을 띄운다.
  - [x] Detail 화면으로 이동할 수 있다.
  - [x] Cart 화면으로 이동할 수 있다.
- [ ] StateFlow / SharedFlow 기반으로 코드를 변경하여 작성한다.

## 4단계 구현 기능 사항

## UI
- [x] 결제 스크린 구현
  - [x] 적용 가능한 쿠폰 컴포넌트가 있다.
  - [x] 금액 관련 정보를 띄우는 컴포넌트가 있다.
  - [x] 뒤로가기 버튼이 있는 결제하기 탑바가 있다.
  - [x] 결제하기 버튼이 있다.
    - [ ] 결제하기 버튼을 누르면 상품 화면으로 이동한다.
- [x] 설정 스크린 구현
  - [ ] 결제 알림을 on / off 할 수 있다.
  - [x] 앱이 재실행 되더라도 유지되어야 한다.
- [x] 상품 스크린에서 설정 스크린으로 이동할 수 있다.
- [ ] 카트 스크린에서 결제 스크린으로 이동할 수 있다.

## 데이터 / 도메인
- [ ] 쿠폰 api를 연결한다.
- [ ] 주문 생성 api를 연결한다.
- [ ] 장바구니에 담긴 상품을 결제할 수 있다.
- [ ] 결제 화면에서 쿠폰을 적용할 수 있다.
  - [ ] 쿠폰을 적용한 가격을 계산할 수 있다.
  - [ ] 쿠폰은 1개만 적용 가능하다.
- [ ] 결제화면에 진입하면 5분 후 결제 알림을 예약한다.
  - [ ] 결제를 완료할 경우 예약된 알림을 취소한다.
  - [ ] 알림을 클릭하면 결제 화면으로 이동한다.
  - [ ] 설정에서 결제 알림을 on / off 할 수 있다.
